# Changelog

All notable changes to TrayReveal, grouped by version in the style of [Keep a Changelog](https://keepachangelog.com/). The section of each version is used as its release notes.

Alle wichtigen Änderungen an TrayReveal, gegliedert nach Version im Stil von [Keep a Changelog](https://keepachangelog.com/de/). Der Abschnitt einer Version wird als ihre Release-Notizen verwendet.

## [1.1.1] – 2026-10-31

### English

#### Changed
- Release notes now come from this changelog in English and German.

#### Fixed
- Notifications show a sharp logo instead of the scaled-up tray icon.

### Deutsch

#### Geändert
- Die Release-Notizen kommen jetzt auf Englisch und Deutsch aus diesem Changelog.

#### Behoben
- Hinweise zeigen ein scharfes Logo statt des hochskalierten Tray-Icons.

## [1.1.0] – 2026-10-30

### English

#### Added
- Installer (`…-setup.exe`) for the current user or all users, with Start menu entry, optional autostart and the usual silent installation parameters; the portable ZIP is still available.
- The exception list shows the icon of each app.
- **Undo last change** reverts the last action from the menu (mode, show/hide all, exceptions).
- Optional update check: once a day TrayReveal asks GitHub for the latest release and announces a new version with a notification and a menu item that opens the release page. Nothing is downloaded or installed automatically; it can be turned off in the menu.
- Five new texts in all 51 languages.

#### Changed
- Exceptions are marked with a red cross over the app icon instead of a check mark.

### Deutsch

#### Neu
- Installer (`…-setup.exe`) für den aktuellen Benutzer oder alle Benutzer, mit Startmenü-Eintrag, optionalem Autostart und den üblichen Parametern für eine stille Installation; das portable ZIP gibt es weiterhin.
- Die Ausnahmeliste zeigt das Icon jeder App.
- **Letzte Änderung rückgängig machen** nimmt die letzte Aktion aus dem Menü zurück (Modus, alle ein-/ausblenden, Ausnahmen).
- Abschaltbare Update-Prüfung: Einmal täglich fragt TrayReveal bei GitHub nach dem neuesten Release und meldet eine neue Version mit einem Hinweis und einem Menüpunkt, der die Release-Seite öffnet. Es wird nichts automatisch heruntergeladen oder installiert; abschaltbar im Menü.
- Fünf neue Texte in allen 51 Sprachen.

#### Geändert
- Ausnahmen sind mit einem roten X über dem App-Icon markiert statt mit einem Haken.

## [1.0.0] – 2026-10-30

### English

#### Added
- 51 languages: the base languages of Windows, German dialects and a few fun languages. Translations were generated by Claude (AI); reviewed ones are listed in `LANGUAGES.md`.
- Right-to-left menus for Arabic and Hebrew.
- Missing texts fall back to a declared language (German for the dialects), otherwise to English.

#### Changed
- First stable release.
- New logo in green.

### Deutsch

#### Neu
- 51 Sprachen: die Basissprachen von Windows, deutsche Dialekte und einige Spaßsprachen. Die Übersetzungen wurden von Claude (KI) erzeugt; geprüfte stehen in `LANGUAGES.md`.
- Menüs von rechts nach links für Arabisch und Hebräisch.
- Fehlende Texte kommen aus einer festgelegten Rückfallsprache (Deutsch bei den Dialekten), sonst aus Englisch.

#### Geändert
- Erste stabile Version.
- Neues Logo in Grün.

## [0.3.0] – 2026-10-30

### English

#### Added
- Entries whose program has been missing for three days in a row are removed from the Windows tray settings.
- Apps with the same name are numbered in the exception list.

#### Fixed
- After an app update, the most recently changed older version decides whether the new one is shown; before, any visible older version won.

### Deutsch

#### Neu
- Einträge, deren Programm drei Tage am Stück fehlt, werden aus den Tray-Einstellungen von Windows entfernt.
- Gleichnamige Apps werden in der Ausnahmeliste durchnummeriert.

#### Behoben
- Nach einem App-Update entscheidet die zuletzt geänderte ältere Version, ob die neue eingeblendet wird; vorher gewann jede sichtbare ältere Version.

## [0.2.0] – 2026-10-30

### English

#### Added
- The menu follows the light or dark mode of the taskbar.

#### Fixed
- Unchecking an exception shows the app again.

### Deutsch

#### Neu
- Das Menü folgt dem hellen oder dunklen Modus der Taskleiste.

#### Behoben
- Wird der Haken einer Ausnahme entfernt, wird die App wieder eingeblendet.

## [0.1.0] – 2026-10-30

### English

#### Added
- First pre-release: tray app with the modes Off, Show new icons and Always show all icons, one-time show/hide all, exceptions, recognition of app updates, notifications, autostart and English and German texts.

### Deutsch

#### Neu
- Erste Vorabversion: Tray-App mit den Modi Aus, Neue Icons einblenden und Immer alle Icons einblenden, einmaligem Ein-/Ausblenden aller Icons, Ausnahmen, Erkennung von App-Updates, Hinweisen, Autostart sowie englischen und deutschen Texten.
